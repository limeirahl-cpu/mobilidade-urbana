# Mobilidade Urbana

MVP de um app de corridas (estilo Uber/99): passageiro pede corrida, motorista aceita e ambos acompanham em tempo real até a conclusão.

- **App**: React Native + Expo (Android/iOS, roda via Expo Go)
- **Backend**: Supabase (Postgres + Auth + Realtime + RLS)
- **Mapas**: Mapbox GL JS (via WebView)

## Começando

Este projeto precisa de chaves de API próprias (Supabase e Mapbox) antes de rodar. Siga o [guia de setup](SETUP.md).

## Como contribuir

1. Crie uma branch a partir da `main`.
2. Faça suas alterações e commit.
3. Abra um Pull Request descrevendo a mudança.
